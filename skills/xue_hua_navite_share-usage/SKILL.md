# xue_hua_navite_share Usage Guide

Provide idiomatic integration patterns, platform setup rules, and best practices for the `xue_hua_navite_share` Flutter plugin across Android, iOS, macOS, Windows, Linux, and Web.

## When to Use

- Sharing plain text, subject lines, or rich URLs (`shareText`, `shareUri`)
- Sharing single or multiple local files (`shareFiles`, `ShareItem.file`)
- Sharing in-memory generated images, PDFs, or JSON payloads without manual temporary file management (`shareMemoryFiles`, `ShareItem.memory`)
- Anchoring share popovers on iPadOS and macOS (`ShareAnchorRect`, `SharePreferredEdge`)
- Invoking targeted system share services directly (`ShareTargetService.airDrop`, `mail`, `messages`, `readingList`, `systemClipboard`, `fileExplorer`)
- Excluding unwanted share activities (`ShareActivityType`, `excludedCustomActivityIdentifiers`) and inspecting `ShareResult`

## Guidelines

* Always use `XueHuaNaviteShare.instance` (or `const XueHuaNaviteShare()`) and await the returned `Future<ShareResult>` to inspect `result.status` (`success`, `dismissed`, `fallbackExecuted`, `unavailable`, `error`) and `result.selectedActivityType`.
* Always pass a `ShareAnchorRect` computed from the triggering button's `RenderBox` (`ShareAnchorRect.fromRect(offset & box.size)`) when supporting iPadOS or macOS so the native popover (`UIPopoverPresentationController` / `NSSharingServicePicker`) anchors directly to the UI control.
* Prefer `ShareItem.memory(bytes: ..., fileName: ...)` when sharing dynamically generated bytes (such as captured screenshots, canvas exports, or generated JSON/PDFs); call `XueHuaNaviteShare.instance.cleanupTempFiles()` after the share workflow finishes to remove cached temporary files on native platforms.
* Check `await XueHuaNaviteShare.instance.canShare(params)` or `await XueHuaNaviteShare.instance.getCapabilities()` before invoking platform-specific targeted services like `ShareTargetService.airDrop`.

## Examples

### Share Text or URL with Popover Anchor

```dart
import 'package:flutter/material.dart';
import 'package:xue_hua_navite_share/xue_hua_navite_share.dart';

Future<void> shareProjectLink(BuildContext buttonContext) async {
  final box = buttonContext.findRenderObject() as RenderBox?;
  final anchor = box != null && box.hasSize
      ? ShareAnchorRect.fromRect(box.localToGlobal(Offset.zero) & box.size)
      : null;

  final result = await XueHuaNaviteShare.instance.shareUri(
    Uri.parse('https://github.com/Matkurban/xue_hua_navite_share'),
    title: 'XueHua Native Share',
    subject: '6-Platform Flutter Native Share Plugin',
    message: 'Check out this cross-platform Flutter share plugin!',
    anchorRect: anchor,
    preferredEdge: SharePreferredEdge.maxY,
    excludedActivityTypes: const [ShareActivityType.print],
  );

  if (result.isSuccess) {
    debugPrint('Shared via: ${result.selectedActivityType}');
  } else if (result.isDismissed) {
    debugPrint('User dismissed the share sheet.');
  }
}
```

### Share Multiple Local and In-Memory Files

```dart
import 'dart:convert';
import 'dart:typed_data';
import 'package:xue_hua_navite_share/xue_hua_navite_share.dart';

Future<void> shareMixedPayload() async {
  final memoryJson = ShareItem.memory(
    bytes: Uint8List.fromList(utf8.encode('{"hello": "world"}')),
    fileName: 'payload.json',
    mimeType: 'application/json',
  );

  final result = await XueHuaNaviteShare.instance.share(
    ShareParams(
      items: [
        memoryJson,
        ShareItem.file('/path/to/photo.png'),
      ],
      title: 'Exported Report & Photo',
      subject: 'Project Export',
      text: 'Attached are the latest report files.',
    ),
  );

  if (result.isSuccess) {
    await XueHuaNaviteShare.instance.cleanupTempFiles();
  }
}
```

### Direct Targeted Service Sharing (AirDrop, Mail, Finder/Explorer, Clipboard)

```dart
import 'package:xue_hua_navite_share/xue_hua_navite_share.dart';

Future<void> shareDirectlyToAirDrop(String filePath) async {
  final params = ShareParams(
    items: [ShareItem.file(filePath)],
    targetService: ShareTargetService.airDrop,
    fallbackToClipboard: true,
  );

  if (await XueHuaNaviteShare.instance.canShare(params)) {
    await XueHuaNaviteShare.instance.share(params);
  }
}
```

## Gotchas

- **iPadOS & macOS Popover Positioning**: Omitting `anchorRect` falls back to centering the popover in the active window. Always resolve the triggering widget's `RenderBox` bounds for a native user experience.
- **macOS App Sandbox Entitlements**: When sharing local files outside the app container or sending emails/network payloads on macOS, ensure `com.apple.security.files.user-selected.read-only` (or `read-write`) and `com.apple.security.network.client` are enabled in `DebugProfile.entitlements` and `Release.entitlements`.
- **Web Share API Context**: Browser `navigator.share` requires a secure context (`https://` or `http://localhost`) and must be triggered directly from a transient user gesture (e.g., button `onPressed`). When unavailable, `fallbackToClipboard: true` gracefully copies text/URLs or triggers a file download and returns `ShareResultStatus.fallbackExecuted`.
